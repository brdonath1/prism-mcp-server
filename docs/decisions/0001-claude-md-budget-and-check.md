# CLAUDE.md on a 3 KB budget; scripts/check.sh as the local gate

Date: 2026-10-21

Decision: `CLAUDE.md` (37,938 bytes before) holds only runtime, commands, the verification gate, boundaries, the autonomy rule and pointers, at or under 3072 bytes, linted by `scripts/claude-md-lint.sh` locally and in the CI `build-and-test` job (checkout and the lint now run on every pull request; the heavy steps stay behind the gate step). The previous file is kept verbatim at `docs/history/claude-md-2026-10-21.md`; its stable facts (what the server is, architecture, environments, run and test, deploy, conventions, gotchas) are distilled into `docs/CONTEXT.md`, and its operator reference (environment-variable table, routing boundary, living-document validation rules, commit prefixes, concurrent-write protocol, brief status, Trigger workflow, the harness-kit block) is read from the history file. The required `contract` check greps CLAUDE.md for the harness-kit managed-block markers and the string "Rule 0", so the new file keeps a three-line managed block that points at the archived text. `scripts/check.sh` runs the `build-and-test` steps locally in CI's order and stamps `.claude/check-ok`, which the installed commit gate requires before any AI `git commit`; `.gitignore` stops ignoring `scripts/check.sh` and `scripts/claude-md-lint.sh`. No runtime pin was added: CI's Node 18 and 20 stay the reference and check.sh warns on a local mismatch; a separate pin pass decides the version (18 is past end of life). `docs/handoffs/CURRENT.md` is created as the live-state file beside the kit's dated handoffs and `LATEST.md`.

Why: the 2026-10-21 environment assessment found this file the largest in the fleet (about 11,000 tokens loaded into every session), most of it reference material no session needs first, while the runtime and the five commands were buried. The gate stops commits that never ran the checks; the lint stops the file growing back.

Source: claude-environment-hygiene `ASSESSMENT.md` sections 5 and 6 and `templates/CLAUDE.repo.md`; claude-config `hooks/commit-gate.py`, `hooks/runtime-guard.py`, `docs/ci-conventions.md`; `.github/workflows/harness-contract.yml`.
